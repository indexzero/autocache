# Security Policy

This policy explains how to report a security vulnerability in autocache.

## Supported versions

autocache is in active development before a stable release. Security fixes land
on the `main` branch. Use the latest commit on `main` for the newest fixes.

## Report a vulnerability

Report a security vulnerability in private. Do not open a public issue for a
security problem.

Use one of these two private channels.

1. Open a private security advisory through GitHub. Go to the Security tab of
   the repository and select "Report a vulnerability".
2. Email the maintainer at
   <!-- PLACEHOLDER: replace with a monitored contact -->
   security@autocache.dev.

Include these details in your report.

* A description of the vulnerability.
* Steps to reproduce the problem.
* The affected package or file.
* Any known impact or exploit path.

## What to expect

A maintainer confirms your report within a few days. The maintainer investigates
the problem and prepares a fix. When you agree, the maintainer credits you in
the release notes.

Please give the maintainer time to release a fix before you disclose the
vulnerability in public.
