# The hypertext lineage

autocache serves old pages as if they never left. The idea that a page is
worth that much care is older than the web, and it has authors.

- **Memex** — Vannevar Bush's hypothetical microfilm desk, on which a reader
  builds and stores associative trails between documents. The unit of value
  was never the document; it was the path through documents. Vannevar Bush,
  ["As We May Think"](https://www.theatlantic.com/magazine/archive/1945/07/as-we-may-think/303881/),
  *The Atlantic*, July 1945.
- **Hypertext** — non-sequential writing: text with branches, which the reader
  traverses. Ted Nelson coined it in a paper whose subtitle names our whole
  territory: *the complex, the changing and the indeterminate*. Ted Nelson,
  ["A File Structure for the Complex, the Changing and the Indeterminate"](https://dl.acm.org/doi/10.1145/800197.806036),
  ACM 20th National Conference, 1965.
- **Transclusion** — inclusion by reference rather than by copy, with
  provenance preserved. The web shipped without it; every mirror since has
  been an apology for that. Nelson, *Literary Machines*, 1981; see
  [the overview](https://en.wikipedia.org/wiki/Transclusion).
- **Xanadu** — Nelson's never-fully-shipped system: bidirectional links,
  transclusion, versioning, micropayment. Its versioning model is the
  temporal axis, named before the web existed. [Project Xanadu](https://xanadu.net),
  from 1960.
- **NLS / Augment** — Douglas Engelbart's system: hierarchical documents,
  view control, linking, the shared Journal, demonstrated in 1968. Engelbart,
  ["Augmenting Human Intellect: A Conceptual Framework"](https://www.dougengelbart.org/content/view/138/),
  SRI, 1962.
- **HyperCard** — Bill Atkinson's stack-of-cards hypermedia system, shipped
  11 August 1987. Cards were scriptable, so a card's content was already
  partly computed rather than stored. Atkinson's stated regret was that it
  was not networked. See [HyperCard](https://en.wikipedia.org/wiki/HyperCard).
- **World Wide Web** — global hypertext over TCP/IP: URI, HTTP, HTML. Tim
  Berners-Lee made the deliberate simplifications — unidirectional links, no
  transclusion, no versioning, link rot tolerated — that made the web ship.
  Berners-Lee, ["Information Management: A Proposal"](https://www.w3.org/History/1989/proposal.html),
  CERN, March 1989.
- **REST and HATEOAS** — the client discovers its transitions from the
  representation it just fetched, not from out-of-band knowledge. Roy T.
  Fielding, [*Architectural Styles and the Design of Network-based Software Architectures*](https://ics.uci.edu/~fielding/pubs/dissertation/top.htm),
  UC Irvine, 2000.
