# The generative axis

The other extension of hypertext: a node that is not a document but a
procedure for producing one. autocache lives on the archival side of this
line, and it needs the line drawn precisely — an archive of generated pages
must capture what produced them, or it captures nothing.

- **Loom** — an interface that treats a language model as a multiverse
  generator: every completion is a branch, the tree is the primary object,
  and the reader prunes and navigates. Janus,
  [socketteer/loom](https://github.com/socketteer/loom), 2020, and
  ["Loom: interface to the multiverse"](https://generative.ink/posts/loom-interface-to-the-multiverse/).
- **Nucleus sampling** — the knobs that select which member of the
  distribution is realized: the coordinates of the generative axis. Holtzman,
  Buys, Du, Forbes, Choi,
  ["The Curious Case of Neural Text Degeneration"](https://arxiv.org/abs/1904.09751),
  ICLR 2020.
- **Retrieval augmentation** — the input state that conditions generation; a
  node's content becomes a function of the path taken to reach it. Lewis et
  al., ["Retrieval-Augmented Generation"](https://arxiv.org/abs/2005.11401),
  NeurIPS 2020.
- **WaveFunctionCollapse** — content generated by constraint propagation on
  demand, deterministic given a seed. The player who visits an unvisited
  place causes it to exist. Maxim Gumin,
  [mxgmn/WaveFunctionCollapse](https://github.com/mxgmn/WaveFunctionCollapse),
  2016.
- **Combinatorial literature** — Queneau's *Cent mille milliards de poèmes*
  (1961): ten sonnets cut into strips, 10^14 readable poems, none of them
  stored. Borges, twice in 1941: the branching-time novel and the total
  library in which the problem is not scarcity but addressing. The
  unread-but-addressable text is a real ontological status, and these are its
  first citizens.
