# The voices

The people whose work this toolkit quietly repeats, organized by what they
would say about it.

Vannevar Bush would recognize the trails. Ted Nelson would say he named all
of this in 1967, and he would be more right than is comfortable — stretchtext,
transclusion, versioning, the docuverse. Douglas Engelbart built view control
in 1968. Andries van Dam shipped hypertext first and spent fifty years
pointing out what the web left behind. Bill Atkinson made the node a program
and regretted only that it was not networked. Jef Raskin, who recruited
Atkinson to Apple, remains the sharpest available critic of any interface
that is neither modeless nor monotonic.

Frank Halasz named versioning and computed structure as unsolved in 1988;
they still are. Wendy Hall kept the links outside the documents. Mark
Bernstein started from total connectivity and authored by removal. Michael
Joyce made node content depend on the path by which you arrived, in 1987,
with no model in sight. Espen Aarseth built the formal apparatus — textons,
scriptons, the traversal function — in
[*Cybertext*](https://en.wikipedia.org/wiki/Cybertext), 1997.

Tim Berners-Lee made the cuts that let the web ship, and this toolkit
re-adds three of them. Roy Fielding would ask what this adds beyond a `Vary`
dimension, and the answer had better be good. Brendan Eich normalized the
computed page. Alan Kay would insist the document was always supposed to be
an object with behavior. Bret Victor would say serving old prose is a
failure of imagination, and we serve it anyway.

Brewster Kahle made the temporal axis exist in practice; his institution is
the one this toolkit leans on, and the one it tries to relieve. Herbert Van
de Sompel and Michael L. Nelson standardized time over HTTP. Leslie Lamport
proved every reading is a linearization. Rich Hickey gave the cleanest
vocabulary for identity, state, and value, and an archive is his epochal
time model built out of other people's pages.

Donald Knuth derived two documents from one source, deterministically, forty
years ago, and would ask for the invariants. Phil Karlton named the two hard
things; Leon Bambrick added the third; Martin Fowler kept the receipts —
for the joke and for event sourcing both, which is either a coincidence or
the whole point.

And Borges, Queneau, Calvino, Saussure, Peirce, Kripke, Aristotle — the
claimants who got there before computing did, and who remind us that the
library was always going to be bigger than the shelf.
